# AI-GRC Workflows

A portfolio-ready starter for an AI-assisted GRC risk assessment workflow. It currently provides a concise landing page and a structured risk assessment workspace. AI integrations, authentication, and persistence are intentionally out of scope for this first iteration.

## Run locally

1. Install [Node.js](https://nodejs.org/) (LTS recommended).
2. Install project dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000).

Use `npm run build` to create a production build.
